Full Shopify Store Development | Luxury Furniture & Home Decor

This project showcases a complete Shopify store that I built independently from the ground up—from planning and branding to development, customization, and launch.

Working closely with the client, I first conducted a comprehensive UX analysis to understand the target audience and customer journey. Based on the research, we carried out a complete brand transformation, including redesigning the logo, creating a new color palette, selecting typography, and establishing a consistent visual identity.

I designed and developed the entire website, including the Home page, Collections, Product pages, About Us, Contact, FAQ, Shipping & Delivery, and Inspiration pages. I also created custom Shopify Liquid sections, responsive layouts, collection carousels, promotional banners, multilingual support, sticky navigation, product recommendations, and mobile-optimized user interfaces.

Every section of the store was strategically designed to increase conversions, improve product discovery, and create a seamless shopping experience. The foundation of the design is user comfort—making navigation intuitive, highlighting products effectively, and strengthening the brand's premium identity across all devices.

This project demonstrates my ability to deliver a complete Shopify solution, combining UX thinking, branding, custom development, and conversion-focused design into a cohesive online store.

Shopify Landing Page Design & Development | Conversion-Focused Campaign

Designed and developed a modern Shopify landing page built to maximize conversions for a promotional marketing campaign.

The page was structured with a clear customer journey, including a compelling hero banner, promotional offers, featured products, trust-building content, benefits section, call-to-action blocks, customer testimonials, and a responsive footer. Every section was carefully positioned to keep visitors engaged and encourage them to take action.

The design follows a clean, premium, and mobile-first approach with strong visual hierarchy, consistent branding, elegant typography, and optimized spacing for an intuitive user experience across all devices.

This landing page helps businesses increase campaign performance by presenting products in a clear, engaging way while reducing distractions and guiding customers towards purchase. It demonstrates my ability to combine Shopify development, UX principles, and conversion-focused design to create high-performing landing pages.

HTML/CSS Website Development | GitHub Pages

Designed and developed a responsive website using HTML and CSS, then deployed it with GitHub Pages for fast and reliable online hosting.

The project includes a modern homepage with well-structured content sections, responsive layouts, clear navigation, and a clean visual design focused on usability and accessibility. The website was built with organized, maintainable code and optimized for both desktop and mobile devices.

Through this project, I strengthened my understanding of front-end web development, responsive design, website structure, and version control using Git and GitHub. It also improved my ability to turn design concepts into fully functional websites.

This type of website is ideal for personal brands, portfolios, small businesses, or startups looking for a professional online presence with a fast, lightweight, and easy-to-maintain solution.
